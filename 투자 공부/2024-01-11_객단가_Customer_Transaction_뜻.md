# 객단가 Customer Transaction 뜻

객단가의 뜻
: 고객 한 명당 평균 구매액이다.

의의
: 유통업을 분석할 때 사용하는 핵심 지표다.
: 고객 한 명에서 발생하는 매출액이 클수록 비용 대비 큰 효용을 얻을 수 있다. (예컨대, 작은 매장을 임대해도 충분하다)
: 전통적인 오프라인 유통업계에서는 직접 발표하는 경우는 드물다.



다양한 객단가
: 온라인 유통망이 성장하면서 다양한 종류의 객단가가 사용되고 있다.



ARPU
: Average Revernue  Per Unit
: 사용자 1명 당 평균 매출액이다.

ARPPU
: Average Revernue Per Paying User
: 유료 사용자 1명 당 평균 매출액이다.
: 접속한 하고 구매는 하지 않는 고객을 제외하고, 실제로 구매를 하는 고객 1명이 발생시키는 평균 매출액을 뜻한다.
